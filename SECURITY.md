# Security

Report vulnerabilities privately through the repository's Security tab using
"Report a vulnerability". If private reporting is unavailable, contact a
maintainer through their published contact channel. Do not put credentials,
connection packages, private response bodies or exploit details in public issues.

Include the SDK version, Node.js version, a minimal synthetic reproduction and
the expected security boundary. Version `0.1.x` is the initial supported line;
security fixes target the latest patch in that line. Response limits, integrity
checks and client-side validation do not replace server-side authorization.
